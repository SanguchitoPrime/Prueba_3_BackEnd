# Bitácora de Prompts IA - Hito 3

Prompt 1: Actúa como un desarrollador Senior especialista en Python, Django y bases de datos Oracle, y configura la conexión con el driver oracledb en settings.py junto con los modelos relacionales TipoMaquinaria y Maquinaria (relación 1:N) en models.py, su registro en admin.py y la vista MaquinariaListView optimizada con select_related('tipo'), considerando que el proyecto es un sistema de control de maquinaria agrícola sobre Oracle Database local que debe evitar consultas N+1 y tener al menos 4 atributos variados en el modelo hijo; entrégame el código Python limpio separado por archivo.

Prompt 2: Actúa como arquitecto de software full stack en Django y Bootstrap 5, y desarrolla el formulario MaquinariaForm en forms.py, las vistas basadas en clases CreateView, UpdateView y DeleteView protegidas con LoginRequiredMixin (respetando MRO) y SuccessMessageMixin en views.py, el mapeo de rutas en urls.py y las plantillas HTML con control de sesión, considerando que solo los usuarios autenticados pueden crear, editar o eliminar maquinarias redirigiendo a /accounts/login/ a usuarios anónimos; entrégame el código completo de cada archivo listo para copiar y pegar.

Prompt 3: Actúa como administrador de bases de datos Oracle y desarrollador Django, y genera un comando de una línea para python manage.py shell junto con las consultas SQL de verificación, considerando que necesito poblar la base de datos Oracle con 4 tipos de maquinaria y 10 equipos vinculados para auditarlos con COUNT e INNER JOIN en Oracle SQL Developer; entrégame únicamente los comandos listos para ejecutar.
